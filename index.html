自傳

軟韌體測試、全端開發

畢業於嘉南藥理大學資訊管理學系，在學期間積極參與產學合作與各類技術競賽。曾加入新竹科學園區研究專案並與長茂科技共同開發產品，累積實際產品開發與跨單位協作經驗；所參與之專題研究亦曾獲校內專題成果展兩度第一名，並於 2020 年台灣綠點子國際發明設計競賽榮獲發明類社會組銀牌獎。

畢業後任職於台鋼集團旗下永洋科技，擔任軟韌體測試工程師。主要負責公司產品之自動化測試開發與維護，熟悉測試流程與測試案例設計。任職期間運用 Python 結合 Selenium 開發 UI 元件自動化測試，有效降低人工驗收錯誤率並提升測試效率；亦曾利用 Python 與 Jenkins 搭配 PDU 建置壓力測試環境。透過自主學習與實務應用，持續為團隊減輕測試負擔並提升系統品質。

為求技術領域的突破與更全面的發展，隨後參與資策會全端工程師就業養成班。在專案實作中，獨立主導並完成 C2C 二手交易市集（Marketplace）系統，前端採用 Vue3 搭配 GSAP 動畫與 RWD 網頁設計，後端則以 ASP.NET Core、EF Core 與 SQL Server 串接 RESTful API，並成功整合綠界金流、物流及 LINE 通知服務。在開發過程中，透過克服版本衝突與環境部署等挑戰，進一步強化了問題分析與解決能力。

我具備良好的邏輯思考能力與高度學習熱忱，重視程式品質與系統穩定度。未來期許能將過去在自動化測試與全端開發所累積的實務經驗相結合，持續深耕軟體工程領域，成為能為團隊帶來實質貢獻的專業工程師。
